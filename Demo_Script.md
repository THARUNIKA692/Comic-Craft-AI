# Comic Craft – Demonstration Script

## 2-Minute Demo Flow

### Introduction

Hello everyone. This is my project, **Comic Craft**, an AI-assisted comic creation application.

The main goal of this project is to convert a user's story or scene description into a comic-style visual panel using generative AI.

### Project Structure

Here I am showing the project structure in VS Code. The project contains the application code, configuration, image-generation logic, and panel storage.

### Development

The application uses Python and an AI image-generation service. The image-generation module sends the prompt to the configured model and receives the generated image.

### Live Demo

Now I will run the application.

I enter a scene description and start the generation process.

The application sends the prompt to the AI image-generation service. After processing, the generated comic image is saved as a panel.

### Comic Preview

Here we can see the generated comic panel in the preview.

This demonstrates the complete workflow:

**User Input → Prompt → AI Image Generation → Comic Panel → Preview**

### Conclusion

Comic Craft demonstrates how generative AI and prompt engineering can be used to simplify visual storytelling and comic creation.
